# Launch runbook

## Required account gates

1. Create GitHub repository `rakhi-battle` and grant the connected GitHub app access.
2. Authenticate Wrangler to the intended Cloudflare account.
3. Deploy once so Wrangler auto-provisions D1, then apply remote migrations.
4. Add a custom domain and update `site`, `APP_ORIGIN`, robots and sitemap URLs.
5. Complete Razorpay merchant activation/KYC; add `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, set `PAYMENTS_ENABLED=true`.
6. Set a random `ADMIN_TOKEN` secret.

## Prelaunch QA

- Creator → link → sibling → result on separate mobile browser.
- Unicode/Hindi nicknames and 24-character names.
- Back/refresh at each step; duplicate completion; invalid/expired ID.
- Story poster download and native share on Android/iPhone.
- Family Court duplicate vote and live aggregation.
- Payment test order, success, failure, tampered signature and reload unlock.
- Analytics funnel and UTMs in `/admin`.
- Chrome, Safari and Instagram in-app browser at 360×800 and 390×844.

## Initial Meta test (approval required before spend)

- Objective: Landing page views for first 150–250 visits; do not claim purchase optimization before event volume exists.
- Geography: India, Hindi + English, ages 18–34, broad audience; exclude no one based on sensitive traits.
- Placements: Instagram Reels + Stories initially; automatic expansion only if downstream data remains attributable.
- Total test: ₹900, three creatives at ₹300 each, one day unless stop-loss hits first.
- Stop-loss: kill creative after 60 landing views if creator completion is below 35%, or after 30 creator completions if challenge-open generation is below 20%; stop all paid traffic if site/payment reliability fails.
- Scale condition: paid visitor value (verified revenue plus conservatively valued attributable organic completions) exceeds CPC with stable pair completion.
